注册并配置 API Key（推荐 DeepSeek V4.1 Flash）

  1. 打开 OpenCode Console 注册并创建 API Key。
  2. API 地址填 https://opencode.ai/inference/openai/v1， 模型填 deepseek-v4.1-flash。
  3. 也可使用 DeepSeek 开放平台 或任意 OpenAI 兼容服务的 Key。
  4. 回到「设置 → AI 设置」保存，之后 AI 问答和 AI 补齐都会使用你的 Key。

免费额度会按服务方规则自动恢复；配置 Key 后不再受免费额度限制。
